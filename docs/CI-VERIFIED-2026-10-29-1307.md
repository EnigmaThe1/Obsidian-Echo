## Included experimental capabilities

1. Android Storage Access Framework folder selection and read-only Markdown ingestion.
2. Local embedding generation and reuse of upstream Echo's on-device Gemma question answering.
3. Filename filtering for common credential and secret paths, and Markdown frontmatter opt-out (`ai-index: false`, `private: true`, `sensitive: true`).
4. Stale imported note removal after successful full scans; no stale cleanup on truncated scans.
5. User-triggered removal of all locally cached imported notes, leaving original Obsidian Markdown untouched.
6. Obsidian-imported content excluded from Echo's plaintext JSON backup.
7. Distinct test app ID to avoid replacing the user's installed Daedalus Echo.

## Known limitations

**CI passing is not Android end-to-end validation.** The imported notes, on-device inference, SAF permissions, source links, live updates, and vault switching need physical-phone testing. Debug APK signing is ephemeral across GitHub builds; an update may require reinstalling the test app. Large notes are currently retrieved mainly through their initial text and not fully chunk-indexed; see [Issue #2](https://github.com/EnigmaThe1/Obsidian-Echo/issues/2). Password and credential lookup remains **unimplemented**, pending a separately authenticated encrypted vault, as tracked in [Issue #1](https://github.com/EnigmaThe1/Obsidian-Echo/issues/1).

No private vault files, audio recordings, passwords, model files or secret signing keys were uploaded to this repository.
